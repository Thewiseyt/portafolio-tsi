## 📖 Descripción del Proyecto

El portafolio personal es un sitio web responsivo y moderno diseñado con HTML5 y CSS3 semánticos. Su propósito es centralizar la trayectoria académica, las competencias técnicas y los proyectos realizados a lo largo del curso, sirviendo como carta de presentación profesional en áreas como redes, ciberseguridad, administración de entornos Linux y desarrollo web.

## 📁 Estructura del Proyecto

La estructura actual del directorio de este proyecto es la siguiente:

```text
portafolio-tsi/
├── img/
│   └── mi-foto.jpg      # Fotografía personal de perfil
├── index.html           # Estructura principal y contenido semántico del portafolio
├── styles.css           # Hoja de estilos (diseño responsivo, variables CSS, layout)
└── README.md            # Documentación descriptiva del proyecto
```

### Detalle de los componentes:
- **`index.html`**: Archivo principal que define la semántica y arquitectura del sitio (barra de navegación, sección de bienvenida *hero*, sección *Sobre mí*, galería de proyectos y pie de página).
- **`styles.css`**: Hoja de estilos que implementa una paleta de colores moderna, tipografías legibles, transiciones fluidas, sistema de diseño responsivo mediante Flexbox y CSS Grid.
- **`img/mi-foto.jpg`**: Imagen personal del estudiante integrada en la sección principal (*hero*).

## 💻 Visualización y Ejecución

Para visualizar el portafolio localmente:

1. Clonar o descargar este repositorio en su equipo local.
2. Abrir el archivo `index.html` directamente en cualquier navegador web moderno (Google Chrome, Mozilla Firefox, Brave, Microsoft Edge, etc.).
3. Alternativamente, se puede desplegar mediante un servidor local, por ejemplo con Python:
   ```bash
   python3 -m http.server 8000
   ```
   Y acceder desde el navegador a `http://localhost:8000`.
